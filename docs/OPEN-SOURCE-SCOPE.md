# 开源范围

社区版公开可以独立审计和运行的本地隐私基础能力，同时与商业发行、支付和企业管理保持明确边界。

## 包含

- OPF 兼容文本 API 与 CLI
- 中国结构化 PII 规则
- 可选 Nym Edge INT8 语义检测
- TXT、CSV、DOCX、XLSX 和 PDF 文件处理
- 本地审核与一次性本地恢复
- 通用 Agent Skill 模板
- 安全边界和威胁模型
- 自动化测试

## 不包含

- 激活码、支付、运营后台和用户数据
- 商业版浏览器扩展发布包
- Windows/macOS 签名安装包
- 安全目录强制 Hook
- OpenAI-compatible 流式隐私网关
- 企业策略、集中审计与自动更新
- 专有规则包和定制模型

公开仓库不应从私有仓库直接镜像。每次发布前都必须重新执行敏感信息检查、依赖许可证检查和完整测试。
