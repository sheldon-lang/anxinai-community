# 安全设计

AnxinAI Community 的核心目标是让 Agent 只接触用户确认过的安全副本。

## 数据边界

- 原始文件由本地 Python 进程读取。
- 映射表写入用户本机的审核状态目录，权限设置为当前用户可读写。
- 命令行输出不包含原始值、映射表和本地审核 URL。
- 审核与恢复服务只绑定环回地址，并使用不可预测的随机令牌。
- 安全副本批准同时绑定原文件和安全副本的 SHA-256。

## 失败关闭

以下情况停止处理：

- 文件格式未知或超过大小限制
- Office 包含无法安全解释的嵌入对象或重复内部路径
- PDF 没有可提取文字层
- XLSX 公式可能在重新计算后恢复敏感值
- 检测到密钥、未发布材料或涉密标识等固定阻断项
- 原文件或安全副本在审核期间变化

## 不在社区版范围内

- 系统级目录监控
- 对所有 Agent 工具调用的强制 Hook
- 系统代理或透明网络代理
- 企业集中策略与审计
- 自动更新服务
