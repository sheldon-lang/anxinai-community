# 威胁模型

## 保护对象

- 原始文件中的个人信息和业务敏感信息
- 占位符与原始值的映射
- 用户本地审核决定
- 生成的安全副本和恢复结果

## 主要威胁

1. Agent 在脱敏前直接读取原文件。
2. 映射或审核令牌进入 Agent 上下文。
3. 审核后文件被替换，旧批准被复用。
4. 非本机请求访问审核或恢复页面。
5. 恶意 Office/PDF 利用压缩包结构、重复路径或嵌入内容绕过处理。
6. 检测漏报导致敏感值仍存在于安全版。

## 已实施缓解

- Skill 明确禁止预读；社区适配必须遵守相同约束。
- CLI 只返回公开摘要，审核 URL 和令牌不进入标准输出。
- SHA-256 将批准绑定到两份文件。
- HTTP 服务限制为环回地址并验证随机令牌。
- Office 处理限制条目数、解压大小和压缩比，并对未知内容失败关闭。
- 规则与语义模型组合检测，高风险凭据默认阻断。

## 剩余风险

- Skill 是 Agent 行为约束，不等同于操作系统强制隔离。
- 规则和模型均可能出现误报与漏报。
- 用户确认了错误的安全版时，工具无法代替用户判断。
- 已经获得原文件系统权限的恶意程序不受本项目约束。
